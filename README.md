# VOLT

Добровольный финансовый сейф: приложение создаёт паузу между импульсом и тратой,
помогая не нарушить решение, которое человек уже принял сам.

> **Beta.** VOLT не хранит и не блокирует реальные деньги — суммы вводятся вручную,
> данные лежат в `localStorage` устройства. Полная концепция — в [`docs/CONCEPT.md`](docs/CONCEPT.md).

## Стек

TanStack Start · React 19 · TypeScript · Vite · Tailwind CSS 4 · shadcn/ui

## Быстрый старт

Нужен [Bun](https://bun.sh) (в репозитории лежит `bun.lock`).

```sh
bun install
bun run dev        # адрес выведет Vite в терминале
```

Через npm тоже работает: `npm install && npm run dev`.

| Команда | Что делает |
| --- | --- |
| `bun run dev` | dev-сервер |
| `bun run build` | production-сборка |
| `bun run preview` | предпросмотр сборки |
| `bun run lint` | ESLint |
| `bun run format` | Prettier |

## Уровни защиты и периоды ожидания

| Уровень | Что происходит при досрочной разблокировке |
| --- | --- |
| 🟢 Спокойный | Напоминание, затем подтверждение |
| 🟡 Осознанный | Вопрос о причине, затем подтверждение |
| 🟠 Охлаждение | Причина → **период охлаждения — 60 минут** → подтверждение |
| 🔴 Железный | Причина → **период заморозки — 24 часа** → подтверждение |

Период сохраняется в `cell.cooling` (в `localStorage`), поэтому переживает закрытие и
перезагрузку приложения. Открыть ячейку досрочно до конца периода нельзя — это проверяется
в `resolveAttempt` (`src/lib/volt/store.tsx`), а не только в интерфейсе.

**Изменить длительность** — одно место: `COOLING_PERIODS` в `src/lib/volt/constants.ts`.
Тексты, таймер и логика подхватят значение автоматически.

## Структура

```
src/
  lib/volt/          бизнес-логика: store, state machine ячейки, PIN, биометрия,
                     статистика, паттерны, достижения, микрокопирайтинг
  components/volt/   экранные компоненты VOLT (UnlockFlow, CellCard, CoolingBanner, …)
  components/ui/     shadcn/ui
  routes/            файловый роутинг TanStack (см. src/routes/README.md)
docs/CONCEPT.md      полная концепция продукта
```

## Работа в команде

- `main` — рабочая ветка; новые задачи делаем в ветках `feature/…` и вливаем через Pull Request.
- `src/routeTree.gen.ts` генерируется автоматически — руками не правим.
- Проект вышел из Lovable. Если он остаётся подключённым к Lovable, не переписываем
  опубликованную git-историю (force push, rebase, squash) — см. `AGENTS.md`.
- Каждая функция должна проходить три проверки из концепции: работает по-настоящему,
  сохраняется после перезагрузки, использует реальные данные (никаких фейковых цифр).
